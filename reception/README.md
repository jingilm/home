# 26期 受付集計アプリ

第5回 石神井高校26期同期会向けの受付・預かり金額集計 PWA です。

## 使い方（この環境）

```bash
cd reception
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

## 機能

- 名簿タップで 1次会（¥9,000）/ 2次会（¥3,000）の受付
- 人数・預かり合計のリアルタイム集計
- 組ジャンプ・名前／旧姓検索
- 当日受付用の予備行
- データはこの端末の `localStorage` にのみ保存

## ホーム画面への追加

スマホのブラウザから「ホーム画面に追加」すると、スタンドアロンアプリとして使えます。
